# Spec 017: Docker, Deployment & Migrations

## Task/Prompt

Implementasi deployment infrastructure:
1. Dockerfile (multi-stage build, distroless, ~20-30MB image)
2. docker-compose.yml (gorouter + PostgreSQL + Redis optional)
3. Database migration system (versioned)
4. Backup/restore utilities
5. Environment variable documentation (.env.example)
6. Single binary release (cross-compile)

Referensi 9Router: Dockerfile, docker-compose, DOCKER.md.

## Tujuan

Deployment yang:
- Single Docker image (~20-30MB)
- docker-compose untuk quick start
- Versioned migrations
- Cross-compile binary untuk multi-platform
- Backup/restore

## Kenapa Tujuan Ini

Tanpa deployment infrastructure, user tidak bisa menjalankan gorouter di production. "Ringan" harus terbukti di Docker image size dan binary size.

5. **Cross-Compile Script**
   ```bash
   #!/bin/bash
   # scripts/build.sh
   VERSION=${1:-"dev"}
   
   # Build for multiple platforms
   PLATFORMS=(
     "linux/amd64"
     "linux/arm64"
     "darwin/amd64"
     "darwin/arm64"
     "windows/amd64"
   )
   
   for PLATFORM in "${PLATFORMS[@]}"; do
     OS=$(echo $PLATFORM | cut -d'/' -f1)
     ARCH=$(echo $PLATFORM | cut -d'/' -f2)
     
     CGO_ENABLED=0 GOOS=$OS GOARCH=$ARCH go build \
       -ldflags="-s -w -X main.Version=$VERSION" \
       -o "dist/gorouter-$VERSION-$OS-$ARCH" \
       ./cmd/server
   done
   ```

## Pseudocode

```
// Migration runner
RunMigrations(db):
  // Ensure _migrations table exists
  db.Exec(`CREATE TABLE IF NOT EXISTS _migrations (
    version TEXT PRIMARY KEY,
    applied_at TIMESTAMPTZ NOT NULL
  )`)
  
  // Get applied migrations
  applied := db.Query("SELECT version FROM _migrations")
  
  // Read embedded migration files
  files := migrationFS.ReadDir("migrations")
  
  // Sort by version number
  sort(files, byVersion)
  
  // Apply pending
  for file in files:
    if file.Version in applied: continue
    
    // Read SQL
    sql := migrationFS.ReadFile(file.Name)
    
    // Execute in transaction
    db.Transaction(func():
      db.Exec(sql)
      db.Exec("INSERT INTO _migrations (version, applied_at) VALUES (?, ?)", file.Version, now)
    )
```
