# Spec 002: Auth System (JWT, Session, Bootstrap Admin)

## Task/Prompt

Implementasi sistem autentikasi dashboard gorouter:
1. Login dengan email + password
2. JWT session (short-lived, secure cookie)
3. Password hashing bcrypt (ringan, proven)
4. Bootstrap admin via environment variable
5. Login audit logging
6. Session expiration
7. Middleware auth untuk dashboard routes

Referensi: 9Router menggunakan bcrypt + JWT (jose library) + secure cookie + 24h expiry.

## Tujuan

Sistem auth yang aman dan ringan:
- Login dashboard untuk admin dan user
- JWT short-lived dengan refresh capability
- Bootstrap admin dari env (zero-setup)
- Semua login attempt tercatat di audit log

## Kenapa Tujuan Ini

Auth adalah gateway semua management API. Tanpa auth:
- Tidak ada user management (spec 003)
- Tidak ada API key management (spec 004)
- Dashboard API tidak aman (spec 014)

### Existing Patterns

- gorouter: Bootstrap via `BOOTSTRAP_ADMIN_EMAIL` + `BOOTSTRAP_ADMIN_PASSWORD`

## Logic Changes

1. **Bootstrap Admin**
   - Cek env `BOOTSTRAP_ADMIN_EMAIL` + `BOOTSTRAP_ADMIN_PASSWORD`
   - Jika user dengan email tersebut belum ada → create admin user
   - Jika sudah ada → skip
   - Password di-hash dengan bcrypt sebelum disimpan

2. **Login Flow**
   ```
   POST /api/auth/login { email, password }
   → Lookup user by email
   → Check status (active/suspended)
   → Verify password (bcrypt compare)
   → Generate JWT { user_id, role, email }
   → Set httpOnly secure cookie
   → Log audit event (login success/failure)
   → Return { success: true }
   ```

3. **JWT Token**
   - Algorithm: HS256
   - Claims: user_id, email, role, exp
   - Expiry: 24h (configurable)
   - Secret: dari env `SESSION_SECRET`
   - Stored di httpOnly, secure, sameSite=lax cookie

4. **Auth Middleware**
   - Parse JWT dari cookie `auth_token`
   - Validate signature + expiry
   - Inject user info ke request context
   - Reject jika invalid/expired

5. **Session Info**
   ```
   GET /api/auth/me
   → Parse JWT dari cookie
   → Return { id, email, name, role, status }
   ```

## Code Changes

1. **internal/auth/password.go**
   - `HashPassword(password string) (string, error)` - bcrypt hash
   - `VerifyPassword(password, hash string) bool` - bcrypt verify

2. **internal/auth/jwt.go**
   - `GenerateToken(user User, secret string, expiry time.Duration) (string, error)`
   - `ValidateToken(token string, secret string) (*Claims, error)`
   - `Claims` struct: UserID, Email, Role, ExpiresAt

3. **internal/auth/bootstrap.go**
   - `BootstrapAdmin(db DatabaseManager, email, password string) error`
   - Idempotent: skip jika admin sudah ada

4. **internal/auth/auth.go**
   - `LoginService` struct dengan db + jwt secret
   - `Login(ctx, email, password) (*TokenResponse, error)`
   - `GetMe(ctx, token) (*User, error)`
   - `Logout()` - clear cookie

5. **internal/middleware/auth.go**
   - `RequireAuth(jwtSecret string) func(http.Handler) http.Handler`
   - Parse cookie → validate JWT → inject context
   - `RequireRole(role string) func(http.Handler) http.Handler`
   - `GetUserFromContext(ctx) *User`

6. **Routes**
   ```
   POST /api/auth/login
   POST /api/auth/logout
   GET  /api/auth/me
   POST /api/auth/change-password
   ```

## Pseudocode

```
// Login flow
POST /api/auth/login:
  body = parse JSON { email, password }
  user = db.Users().FindByEmail(email)
  if user == nil → return 401 "Invalid credentials"
  if user.Status != "active" → return 403 "Account suspended"
  if !VerifyPassword(password, user.PasswordHash) →
    audit.Log("login_failed", user.ID, email)
    return 401 "Invalid credentials"
  
  token = GenerateToken(user, config.SessionSecret, 24h)
  audit.Log("login_success", user.ID, email)
  
  set cookie "auth_token" = token {
    httpOnly: true,
    secure: config.IsProduction,
    sameSite: "Lax",
    path: "/",
    maxAge: 86400
  }
  return 200 { success: true, user: { id, email, name, role } }

// Bootstrap admin (at startup)
BootstrapAdmin(db, email, password):
  user = db.Users().FindByEmail(email)
  if user != nil → return nil  // already exists
  hash = HashPassword(password)
  user = User{
    ID:           uuid.New(),
    Email:        email,
    Name:         "Admin",
    Role:         "admin",
    Status:       "active",
    PasswordHash: hash,
    CreatedAt:    time.Now(),
    UpdatedAt:    time.Now(),
  }
  db.Users().Create(user)
  audit.Log("bootstrap_admin_created", user.ID, email)
```
