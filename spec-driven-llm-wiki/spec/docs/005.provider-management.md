# Spec 005: Provider Management (Credentials, Encryption, Cooldown)

## Task/Prompt

Implementasi provider connection management:
1. CRUD provider connections (create, read, update, delete, test)
2. Provider types: api_key, oauth, headers, no_auth
3. Credential encryption: AES-256-GCM
4. Multi-account per provider
5. Priority + weight untuk routing
6. Status: active, disabled, error, cooldown
7. Cooldown mechanism (rate limit, quota exceeded)
8. Test connection endpoint

Referensi 9Router: provider connections, provider nodes, encrypted secrets, status tracking.

## Tujuan

Sistem provider management yang:
- Credential disimpan terenkripsi (AES-256-GCM)
- Credential tidak ditampilkan ulang setelah disimpan
- Multi-account support dengan priority/weight
- Cooldown otomatis saat rate limited

## Kenapa Tujuan Ini

Provider connections adalah inti routing (spec 010, 011):
- Gateway (spec 010) butuh provider credentials
- Combo fallback (spec 011) butuh multi-account selection
- Quota tracking (spec 012) butuh provider state

## Logic Changes

1. **Provider Connection Model**
   ```go
   type ProviderConnection struct {
       ID             string    // UUID
       Provider       string    // "openai", "glm", "minimax", etc.
       Name           string    // Label untuk admin
       AuthType       string    // "api_key" | "oauth" | "headers" | "no_auth"
       EncryptedSecret []byte   // AES-256-GCM encrypted
       BaseURL        string    // Untuk compatible provider
       Priority       int       // Lower = higher priority
       Weight         int       // Untuk weighted round-robin
       Status         string    // "active" | "disabled" | "error" | "cooldown"
       CooldownUntil  *time.Time
       LastError      string
       LastErrorAt    *time.Time
       BackoffLevel   int       // Exponential backoff level
       CreatedBy      string    // Admin UUID
       CreatedAt      time.Time
       UpdatedAt      time.Time
   }

   type Credential struct {
       APIKey      string  // untuk api_key type
       OAuthToken  string  // untuk oauth type
       Headers     map[string]string // untuk headers type
       // Tidak ada field untuk no_auth
   }
   ```

2. **Encryption Flow**
   ```
   Master Key: dari env SECRET_ENCRYPTION_KEY (32 bytes base64)
   
   Encrypt(credential):
     key = decodeBase64(env.SECRET_ENCRYPTION_KEY)
     nonce = random(12 bytes)
     ciphertext = AES-256-GCM(key, nonce, credential)
     return nonce + ciphertext  // stored in DB
   
   Decrypt(stored):
     nonce = stored[:12]
     ciphertext = stored[12:]
     key = decodeBase64(env.SECRET_ENCRYPTION_KEY)
     return AES-256-GCM-Decrypt(key, nonce, ciphertext)
   ```

3. **Cooldown Mechanism**
   ```
   On error (429, 503, etc):
     if provider reports reset_at_ms:
       cooldown_until = reset_at_ms
     else:
       cooldown_until = now + exponentialBackoff(backoffLevel)
       backoffLevel++
   
   On success:
     clear cooldown_until
     reset backoffLevel = 0
   
   Exponential backoff: min(2^level * 2s, 5min), max level 15, hard cap 30min
   ```

4. **Test Connection**
   ```
   TestConnection(providerID):
     conn = GetConnection(providerID)
     cred = Decrypt(conn.EncryptedSecret)
     
     // Build test request berdasarkan provider type
     switch conn.Provider:
       "openai" → POST /v1/models with API key
       "glm" → POST /v1/chat/completions with API key
       "minimax" → POST /v1/chat/completions with API key
       etc.
     
     if response OK:
       return { success: true, latency_ms }
     else:
       return { success: false, error: "rate limit", status }
   ```

5. **Multi-Account Selection**
   ```
   GetActiveAccounts(provider, excludeIDs []string):
     accounts = repo.FindByProvider(provider)
     return accounts.Filter(
       status == "active" AND
       (cooldown_until == null OR cooldown_until < now) AND
       id NOT IN excludeIDs
     ).Sort(by priority ASC)
   ```

## Pseudocode

```
CreateProvider(adminID, input):
  cred = Credential{
    APIKey: input.APIKey,
    // OAuth, Headers handling
  }
  key = secrets.GetMasterKey()
  encrypted = EncryptCredential(cred, key)
  
  conn = ProviderConnection{
    ID: uuid.New(), Provider: input.Provider, Name: input.Name,
    AuthType: input.AuthType, EncryptedSecret: encrypted,
    BaseURL: input.BaseURL, Priority: input.Priority,
    Weight: input.Weight, Status: "active",
    CreatedBy: adminID, CreatedAt: now, UpdatedAt: now,
  }
  repo.Create(conn)
  audit.Log("provider_created", adminID, { provider, name })
  
  // Return WITHOUT decrypted secret
  return conn  // Cred hanya di-set saat create, tidak di-return

TestProvider(id):
  conn = repo.FindByID(id)
  cred = Decrypt(conn.EncryptedSecret, secrets.GetMasterKey())
  
  // Build test request
  req = buildTestRequest(conn.Provider, conn.BaseURL, cred)
  
  resp, err = httpClient.Do(req)
  latency = time.Since(start)
  
  if err != nil:
    MarkCooldown(id, now.Add(30s), err.Error())
    return { success: false, error: err.Error(), latency_ms: latency }
  
  if resp.StatusCode >= 200 && resp.StatusCode < 300:
    ClearCooldown(id)
    return { success: true, latency_ms: latency }
  
  // Rate limited or error
  MarkCooldownFromResponse(id, resp)
  return { success: false, error: parseError(resp), status: resp.StatusCode }
```
