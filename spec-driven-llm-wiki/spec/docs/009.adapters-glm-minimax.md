# Spec 009: Adapters: GLM & MiniMax

## Task/Prompt

Implementasi adapter untuk:
1. **GLM / Zhipu** - Chinese LLM provider
2. **MiniMax** - Chinese LLM provider dengan long context

Kedua provider dianggap OpenAI-compatible dengan perbedaan minor yang perlu di-mapping.

Referensi 9Router: glm executor, minimax executor, quota fetchers, OpenAI-compatible mode.

## Tujuan

Adapter GLM dan MiniMax yang:
- Berbasis OpenAI-compatible adapter (spec 008)
- Mapping perbedaan format jika ada
- Quota fetch (jika provider support)
- Usage parse yang benar

## Kenapa Tujuan Ini

GLM dan MiniMax adalah provider wajib v0.1 (PRD Section 6.4). Provider ini murah dan sering dipakai sebagai fallback.

## Logic Changes

1. **GLM Adapter**
   ```go
   type GLMAdapter struct {
       BaseURL string  // default: "https://open.bigmodel.cn/api/paas/v4"
   }
   ```
   
   GLM API endpoints:
   - Chat: `POST /chat/completions` (OpenAI-compatible)
   - Models: `GET /models`
   
   Differences from OpenAI:
   - Different model names: `glm-4-plus`, `glm-4-flash`, `glm-4.5`
   - Token counting mungkin beda
   - Error format mungkin slightly different
   - Auth: JWT token generation dari API key (Zhipu-specific)
   
   Zhipu Auth (special):
   ```
   API Key format: {id}.{secret}
   Generate JWT:
     header = base64({alg:"HS256",sign_type:"SIGN"})
     payload = base64({api_key:id, exp: now+1h, timestamp: now})
     signature = HMAC-SHA256(header+"."+payload, secret)
     token = header+"."+payload+"."+signature
   Authorization: Bearer {token}
   ```

2. **MiniMax Adapter**
   ```go
   type MiniMaxAdapter struct {
       BaseURL string  // default: "https://api.minimax.chat/v1"
   }
   ```
   
   MiniMax API endpoints:
   - Chat: `POST /text/chatcompletion_v2` (OpenAI-compatible format)
   - Models: support long context models
   
   Differences from OpenAI:
   - Different endpoint path
   - Model names: `MiniMax-Text-01`, `abab6.5s-chat`
   - Usage parse slightly different
   - Quota endpoint available

3. **Common Pattern** (extend OpenAI adapter)
   ```
   GLMAdapter:
     extends OpenAICompatibleAdapter
     overrides: TranslateRequest (JWT auth), ParseResponse (finish_reason mapping)
   
   MiniMaxAdapter:
     extends OpenAICompatibleAdapter
     overrides: TranslateRequest (different endpoint path)
   ```

4. **Usage Parse**
   ```
   GLM:  { prompt_tokens, completion_tokens, total_tokens }  // same as OpenAI
   MiniMax: { prompt_tokens, completion_tokens, total_tokens }  // same as OpenAI
   ```

## Pseudocode

```
// GLM Adapter - TranslateRequest
func (a *GLMAdapter) TranslateRequest(ctx, req, cred):
  // Generate Zhipu JWT token
  parts := strings.SplitN(cred.APIKey, ".", 2)
  token := generateZhipuJWT(parts[0], parts[1])
  
  openaiReq := mapNormalizedToOpenAI(req)
  openaiReq["model"] = extractModelName(req.Model)  // "glm/glm-4.5" → "glm-4.5"
  
  body := json.Marshal(openaiReq)
  httpReq := http.NewRequest("POST", a.baseURL+"/chat/completions", body)
  httpReq.Header.Set("Authorization", "Bearer "+token)
  httpReq.Header.Set("Content-Type", "application/json")
  return httpReq, nil

// Zhipu JWT Generation
func generateZhipuJWT(id, secret string) string:
  now := time.Now().UnixMilli()
  header := base64(json.marshal({alg:"HS256",sign_type:"SIGN"}))
  payload := base64(json.marshal({api_key:id, exp:now+3600000, timestamp:now}))
  signature := hmacSHA256(header+"."+payload, secret)
  return header + "." + payload + "." + base64(signature)

// MiniMax Adapter - TranslateRequest
func (a *MiniMaxAdapter) TranslateRequest(ctx, req, cred):
  openaiReq := mapNormalizedToOpenAI(req)
  openaiReq["model"] = extractModelName(req.Model)  // "minimax/MiniMax-M1" → "MiniMax-M1"
  
  body := json.Marshal(openaiReq)
  httpReq := http.NewRequest("POST", a.baseURL+"/text/chatcompletion_v2", body)
  httpReq.Header.Set("Authorization", "Bearer "+cred.APIKey)
  httpReq.Header.Set("Content-Type", "application/json")
  return httpReq, nil
```
