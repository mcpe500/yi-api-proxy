# Spec 001: Project Scaffold, Config & DatabaseManager

## Task/Prompt

Membuat struktur project gorouter (Go AI API Gateway) dengan:
1. Go module initialization
2. cmd/server/main.go entry point
3. internal/ directory layout sesuai Go conventions
4. Config via environment variables (ringan, no config file needed)
5. DatabaseManager abstraction (JSON/SQLite/PostgreSQL)
6. Logger menggunakan slog (stdlib)
7. Graceful shutdown
8. Basic health check endpoint

## Tujuan

Membangun fondasi project gorouter yang:
- **Ringan**: Single binary, zero external services required (default SQLite)
- **Simple**: Config via env, no config file needed
- **Flexible**: 3 driver mode (JSON/SQLite/PostgreSQL) via DatabaseManager
- **Portable**: Pure Go (modernc.org/sqlite), no CGO, cross-compile friendly

## Kenapa Tujuan Ini

Fondasi harus kuat karena semua spec lain depend padanya:
- DatabaseManager dipakai di seluruh aplikasi
- Config pattern dipakai di semua komponen
- Logger slog dipakai everywhere
- Tanpa fondasi ini, spec lain tidak bisa diimplement

## Pseudocode

```go
// main.go
func main() {
    // 1. Load config from env
    cfg := config.Load()

    // 2. Initialize logger
    log := logger.New(cfg.LogLevel)
    log.Info("Starting gorouter", "version", Version)

    // 3. Initialize DatabaseManager
    db, err := dbmanager.New(cfg.DatabaseDriver, cfg.DatabaseDSN)
    if err != nil {
        log.Error("Failed to connect database", "error", err)
        os.Exit(1)
    }
    defer db.Close()

    // 4. Run migrations
    if err := db.Migrate(); err != nil {
        log.Error("Failed to run migrations", "error", err)
        os.Exit(1)
    }

    // 5. Setup router
    r := chi.NewRouter()
    r.Use(middleware.Logger(log))
    r.Use(middleware.Recover(log))

    // 6. Register routes
    registerHealthRoutes(r, db)

    // 7. Start server with graceful shutdown
    srv := &http.Server{
        Addr:    cfg.ListenAddr,
        Handler: r,
    }

    go func() {
        log.Info("Server listening", "addr", cfg.ListenAddr)
        if err := srv.ListenAndServe(); err != nil && err != http.ErrServerClosed {
            log.Error("Server error", "error", err)
        }
    }()

    // 8. Wait for shutdown signal
    sig := waitForSignal()
    log.Info("Shutting down", "signal", sig)

    ctx, cancel := context.WithTimeout(context.Background(), 30*time.Second)
    defer cancel()
    srv.Shutdown(ctx)

    log.Info("Server stopped")
}
```

```go
// dbmanager.go
type DatabaseManager interface {
    Driver() string
    Connect() error
    Close() error
    Migrate() error
    Users() UserRepository
    ApiKeys() ApiKeyRepository
    Providers() ProviderRepository
    Models() ModelRepository
    Combos() ComboRepository
    UsageEvents() UsageRepository
    AuditLogs() AuditRepository
    Settings() SettingsRepository
}

func New(driver, dsn string) (DatabaseManager, error) {
    switch driver {
    case "json":
        return newJSONDriver(dsn)
    case "sqlite":
        return newSQLiteDriver(dsn)
    case "postgres", "postgresql":
        return newPostgresDriver(dsn)
    default:
        return nil, fmt.Errorf("unsupported driver: %s", driver)
    }
}
```
