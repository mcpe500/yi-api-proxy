# Spec 012: Quota, Rate Limit & Budget Enforcement

## Task/Prompt

Implementasi quota dan rate limiting:
1. User-level quota policies (daily/monthly limits)
2. Model/provider allowlist/denylist
3. Rate limit per user/key (RPM, TPM)
4. Budget enforcement (max cost per month)
5. Max context length enforcement
6. Pre-request validation (reject sebelum ke provider)
7. Quota reset manual oleh admin

Referensi 9Router: quota tracking, rate limit, budget limits, pre-request check.

## Tujuan

Quota system yang:
- Enforce limits sebelum request ke provider (save cost)
- Flexible policy: per-user, per-key, per-model
- Rate limiting (RPM, TPM) dengan Redis atau in-memory
- Budget tracking

## Kenapa Tujuan Ini

Tanpa quota, user bisa abuse sistem:
- Overuse → biaya provider naik
- Rate limit dari provider → reputasi buruk
- Budget overrun → tidak terkontrol

## Logic Changes

1. **Quota Policy Model**
   ```go
   type QuotaPolicy struct {
       ID           string   // UUID
       TargetType   string   // "user" | "api_key"
       TargetID     string   // user_id or api_key_id
       PolicyType   string   // "daily_requests" | "monthly_tokens" | "monthly_cost"
       Limit        int64    // 1000, 10000000, 1000 (cents)
       ModelPattern string   // "*" for all, "glm/*", "openai/gpt-4o"
       Provider     string   // "*" for all
       Period       string   // "day" | "month"
       CreatedAt    time.Time
       UpdatedAt    time.Time
   }

   type RateLimitRule struct {
       ID           string
       TargetType   string   // "user" | "api_key"
       TargetID     string
       LimitType    string   // "rpm" (requests per minute) | "tpm" (tokens per minute)
       Limit        int
       Window       int      // seconds (60 for rpm, 60 for tpm)
   }

   type ModelPermission struct {
       ID          string   // UUID
       TargetType   string   // "user" | "api_key"
       TargetID     string
       Pattern      string   // "glm/*", "openai/gpt-4o"
       AccessType   string   // "allow" | "deny"
   }
   ```

2. **Quota Check Flow**
   ```
   CheckQuota(userID, modelID, tokensEstimate):
     policies = GetPolicies(userID)
     
     for policy in policies:
       // Filter by model/provider
       if !matchesPattern(policy, modelID): continue
       
       // Check limit
       currentUsage = GetUsage(policy, userID, period)
       if currentUsage >= policy.Limit:
         return QuotaExceeded{Policy: policy, Current: currentUsage, Limit: policy.Limit}
     
     return QuotaOK
   ```

3. **Rate Limit Check (Token Bucket)**
   ```
   CheckRateLimit(key, limitType, limit, window):
     bucket = GetBucket(key, limitType)
     
     if bucket.Tokens < 1:
       return RateLimited{RetryAfter: bucket.RefillIn}
     
     bucket.Tokens--
     SaveBucket(bucket)
     return RateLimitOK
   ```

4. **In-Memory Rate Limiter (Default)**
   ```go
   type MemoryStore struct {
       mu      sync.RWMutex
       buckets map[string]*TokenBucket
   }

   type TokenBucket struct {
       Tokens    float64
       LastRefill time.Time
       Limit     int
       Window    int
   }

   func (s *MemoryStore) Allow(key string, limit int, window int) (bool, int) {
       s.mu.Lock()
       defer s.mu.Unlock()
       
       bucket := s.buckets[key]
       if bucket == nil {
           bucket = &TokenBucket{Tokens: float64(limit), Limit: limit, Window: window}
           s.buckets[key] = bucket
       }
       
       // Refill
       now := time.Now()
       elapsed := now.Sub(bucket.LastRefill).Seconds()
       refill := (elapsed / float64(window)) * float64(bucket.Limit)
       bucket.Tokens = min(float64(bucket.Limit), bucket.Tokens+refill)
       bucket.LastRefill = now
       
       if bucket.Tokens >= 1 {
           bucket.Tokens--
           return true, 0
       }
       
       retryAfter := int((1 - bucket.Tokens) / (float64(bucket.Limit) / float64(window)))
       return false, retryAfter
   }
   ```

5. **Redis Rate Limiter (Optional)**
   - Use Redis INCR + EXPIRE untuk sliding window
   - Support distributed rate limiting
   - Fallback to in-memory jika Redis unavailable

6. **Budget Tracking**
   ```
   TrackCost(userID, cost):
     current = GetBudgetUsage(userID, "month")
     newTotal = current + cost
     limit = GetBudgetLimit(userID)
     
     if newTotal >= limit:
       // Already over budget - still allow but warn
       NotifyBudgetExceeded(userID)
     
     SaveBudgetUsage(userID, "month", newTotal)
   ```

7. **Pre-Request Validation**
   ```
   ValidateRequest(userID, apiKeyID, modelID, estimatedTokens):
     // 1. Model permission check
     if !CanUseModel(userID, modelID):
       return Error("model_forbidden")
     
     // 2. Quota check
     quotaCheck = CheckQuota(userID, modelID, estimatedTokens)
     if !quotaCheck.OK:
       return Error("quota_exceeded")
     
     // 3. Rate limit check
     rateCheck = CheckRateLimit(userID, "rpm", user.RPM, 60)
     if !rateCheck.OK:
       return Error("rate_limited")
     
     rateCheck = CheckRateLimit(userID, "tpm", user.TPM, 60)
     if !rateCheck.OK:
       return Error("rate_limited")
     
     return OK
   ```

## Pseudocode

```
CheckQuota(userID, apiKeyID, modelID, tokens):
  // Get all applicable policies
  policies := quotaStore.GetPolicies(userID)
  
  for policy in policies:
    // Check model/provider match
    if !patternMatch(policy.ModelPattern, modelID): continue
    if policy.Provider != "*" and !startsWith(modelID, policy.Provider+"/"): continue
    
    // Get current usage for this period
    usage := quotaStore.GetUsage(userID, policy.ID, policy.Period)
    
    if policy.PolicyType == "daily_requests" or "monthly_tokens":
      if usage.Count + 1 > policy.Limit:
        return QuotaExceeded(policy, usage.Count, policy.Limit)
      
    if policy.PolicyType == "monthly_cost":
      if usage.Cost + estimateCost(tokens) > policy.Limit:
        return QuotaExceeded(policy, usage.Cost, policy.Limit)
  
  return QuotaOK

RecordUsage(userID, apiKeyID, modelID, tokens, cost):
  for policy in quotaStore.GetPolicies(userID):
    if matches(policy, modelID):
      quotaStore.IncrementUsage(userID, policy.ID, tokens, cost)
```
