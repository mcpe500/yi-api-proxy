# Spec 010: Gateway /v1 Endpoints (Chat Completions, Streaming SSE, Models)

## Task/Prompt

Implementasi OpenAI-compatible gateway endpoints:
1. `POST /v1/chat/completions` - Chat completions (streaming + non-streaming)
2. `GET /v1/models` - Model list (filtered by user permission)
3. SSE streaming implementation
4. API key authentication middleware
5. Request pipeline: auth → validate → resolve → translate → execute → respond
6. Error response (OpenAI-compatible format)
7. Usage tracking integration

Referensi 9Router: /v1/* routes, streaming handler, request pipeline.

## Tujuan

Gateway yang:
- OpenAI-compatible (SDK langsung jalan)
- Streaming SSE support
- Request pipeline yang jelas
- Error handling konsisten
- Usage tracking setiap request

## Kenapa Tujuan Ini

Gateway adalah endpoint utama yang dipakai oleh user/tools. Ini adalah "product" utama gorouter. Semua spec lain (auth, keys, providers, adapters, routing) semuanya mengarah ke sini.

## Logic Changes

1. **Request Pipeline**
   ```
   Client Request
     → CORS middleware
     → API key auth middleware
     → Load user + permissions
     → Validate request (JSON parsing)
     → Resolve model (direct, alias, combo - spec 011)
     → Check model permission (CanUseModel)
     → Get provider adapter (registry)
     → Get provider account (active, not cooldown)
     → Translate request via adapter
     → Execute upstream request
     → If error eligible → fallback (spec 011)
     → Normalize response via adapter
     → Stream/non-stream response to client
     → Record usage event
   ```

2. **SSE Streaming**
   ```go
   func handleStreamingResponse(w http.ResponseWriter, events <-chan StreamEvent) {
       w.Header().Set("Content-Type", "text/event-stream")
       w.Header().Set("Cache-Control", "no-cache")
       w.Header().Set("Connection", "keep-alive")
       w.Header().Set("Access-Control-Allow-Origin", "*")
       
       flusher, _ := w.(http.Flusher)
       
       for event := range events {
           if event.Done {
               fmt.Fprintf(w, "data: [DONE]\n\n")
               flusher.Flush()
               return
           }
           chunk := buildOpenAIChunk(event)
           fmt.Fprintf(w, "data: %s\n\n", json.Marshal(chunk))
           flusher.Flush()
       }
   }
   ```

4. **Chat Completions Handler**
   ```go
   func (h *ChatHandler) ServeHTTP(w http.ResponseWriter, r *http.Request) {
       // 1. Parse request
       body, err := parseChatRequest(r)
       
       // 2. Validate API key
       validation := GetKeyValidation(r.Context())
       
       // 3. Resolve model
       modelID, err := h.modelService.ResolveModel(body.Model)
       
       // 4. Check permission
       if !h.modelService.CanUseModel(ctx, validation.UserID, modelID) {
           return errorResponse(w, 403, "model_forbidden")
       }
       
       // 5. Build normalized request
       req := buildNormalizedRequest(body, validation, modelID)
       
       // 6. Execute (with fallback via routing service)
       result, err := h.routingService.ExecuteWithFallback(ctx, req)
       
       // 7. Response
       if req.Stream {
           handleStreamingResponse(w, result.StreamEvents)
       } else {
           handleNonStreamingResponse(w, result.Response)
       }
       
       // 8. Record usage
       h.usageService.RecordEvent(ctx, result.UsageEvent)
   }
   ```

5. **Error Response Format** (OpenAI-compatible)
   ```go
   func errorResponse(w http.ResponseWriter, status int, code string) {
       w.WriteHeader(status)
       json.NewEncoder(w).Encode(map[string]any{
           "error": map[string]any{
               "message": errorMessages[code],
               "type":    errorTypes[status],
               "code":    code,
           },
       })
   }
   ```
   
   Error codes:
   ```
   missing_api_key    → 401
   invalid_api_key    → 401
   user_suspended     → 403
   model_forbidden    → 403
   quota_exceeded     → 429
   rate_limited       → 429
   provider_unavailable → 503
   all_providers_failed → 503
   invalid_request    → 400
   context_length_exceeded → 400
   ```

6. **/v1/models Handler**
   ```go
   func (h *ModelsHandler) ServeHTTP(w http.ResponseWriter, r *http.Request) {
       validation := GetKeyValidation(r.Context())
       models := h.modelService.GetVisibleModels(ctx, validation.UserID)
       
       w.Header().Set("Content-Type", "application/json")
       json.NewEncoder(w).Encode(map[string]any{
           "object": "list",
           "data": models.Map(m => map[string]any{
               "id":       m.ID,
               "object":   "model",
               "created":  m.CreatedAt.Unix(),
               "owned_by": m.Provider,
           }),
       })
   }
   ```

## Pseudocode

```
// Full request flow for POST /v1/chat/completions
POST /v1/chat/completions:
  // Middleware chain
  cors → apikey_auth → request_logger → handler
  
  // Handler
  body = parseJSON(request.body)
  if body.model is empty → 400 "model required"
  
  apiKey = GetKeyValidation(ctx)
  modelID = resolveModel(body.model)  // alias → provider/model
  if !canUseModel(apiKey.UserID, modelID) → 403 "model_forbidden"
  
  // Build normalized request
  req = NormalizedChatRequest{
    RequestID: uuid.New(),
    UserID:    apiKey.UserID,
    Model:     modelID,
    Messages:  body.messages,
    Stream:    body.stream,
    Temperature: body.temperature,
    ...
  }
  
  // Execute via routing service (handles provider selection + fallback)
  result = routingService.Execute(ctx, req)
  
  // Response
  if body.stream:
    SSE headers
    for event in result.StreamEvents:
      write "data: " + json(event) + "\n\n"
      flush
    write "data: [DONE]\n\n"
  else:
    JSON response (OpenAI format)
  
  // Usage tracking (async)
  usageService.RecordAsync(UsageEvent{
    RequestID:       req.RequestID,
    UserID:          req.UserID,
    ApiKeyID:        apiKey.KeyID,
    RequestedModel:  body.model,
    FinalModel:      result.Model,
    Provider:        result.Provider,
    StatusCode:      result.StatusCode,
    PromptTokens:    result.Usage.PromptTokens,
    CompletionTokens: result.Usage.CompletionTokens,
    LatencyMs:       result.LatencyMs,
    IsStream:        body.stream,
  })
```
