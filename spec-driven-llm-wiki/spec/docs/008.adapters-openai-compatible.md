# Spec 008: Adapters: OpenAI & OpenAI-Compatible

## Task/Prompt

Implementasi 2 adapter:
1. **OpenAI adapter** - Native OpenAI API (api.openai.com)
2. **OpenAI-compatible adapter** - Custom base URL dengan OpenAI-compatible endpoint

Fitur yang harus didukung:
- Chat completions (streaming + non-streaming)
- Tool calls / function calls
- JSON mode
- Usage parsing
- Embeddings (OpenAI adapter)
- Error parsing dan mapping

Referensi 9Router: openai executor, openai-compatible nodes, streaming SSE.

## Tujuan

Adapter OpenAI yang:
- Passthrough (sudah OpenAI format, minimal translation)
- Streaming SSE support
- Tool call support
- Embeddings support
- Custom base URL untuk provider compatible

## Kenapa Tujuan Ini

OpenAI adapter adalah adapter paling penting:
- Gateway (spec 010) butuh adapter untuk chat completions
- OpenAI-compatible adalah basis untuk GLM/MiniMax (spec 009)
- Banyak provider menggunakan OpenAI-compatible API

## Logic Changes

1. **OpenAI Adapter** (passthrough)
   - Request: NormalizedChatRequest → OpenAI request (near identical)
   - Response: OpenAI response → NormalizedChatResponse (near identical)
   - Stream: OpenAI SSE → Normalized StreamEvent
   - Embeddings: NormalizedEmbeddingRequest → OpenAI embeddings
   - Capabilities: chat, streaming, tools, vision, json_mode, embeddings

2. **OpenAI-Compatible Adapter**
   - Sama dengan OpenAI adapter tapi dengan custom base URL
   - Admin set: base_url, api_key, auth_header
   - Capabilities configurable oleh admin

3. **SSE Streaming**
   ```
   Parse OpenAI SSE stream:
     for each line:
       if line starts with "data: ":
         data = line[6:]
         if data == "[DONE]":
           yield StreamEvent{Done: true}
         else:
           chunk = parseJSON(data)
           yield StreamEvent{
             ID:    chunk.id,
             Model: chunk.model,
             Delta: chunk.choices[0].delta,
             Usage: chunk.usage,  // if present (final chunk)
           }
   ```

4. **Tool Call Handling**
   ```
   Request with tools:
     tools[] → OpenAI tools format (passthrough)
     tool_choice → OpenAI tool_choice format
   
   Response with tool calls:
     choices[0].message.tool_calls → Normalized tool_calls
     choices[0].delta.tool_calls → Streaming tool call deltas
   ```

5. **Embeddings**
   ```go
   type NormalizedEmbeddingRequest struct {
       Model          string
       Input          any  // string or []string
       EncodingFormat string // "float"
       Dimensions     int
   }

   type NormalizedEmbeddingResponse struct {
       Object string
       Data   []EmbeddingData
       Model  string
       Usage  EmbeddingUsage
   }
   ```

## Pseudocode

```
// OpenAI Adapter - TranslateRequest
func (a *OpenAIAdapter) TranslateRequest(ctx, req, cred):
  openaiReq := map[string]any{
    "model":    extractModelName(req.Model),  // "openai/gpt-4o" → "gpt-4o"
    "messages": mapMessages(req.Messages),
    "stream":   req.Stream,
  }
  if req.Temperature != nil: openaiReq["temperature"] = *req.Temperature
  if req.MaxTokens != nil: openaiReq["max_tokens"] = *req.MaxTokens
  if req.Tools != nil: openaiReq["tools"] = mapTools(req.Tools)
  if req.ToolChoice != nil: openaiReq["tool_choice"] = req.ToolChoice
  if req.ResponseFormat != nil: openaiReq["response_format"] = req.ResponseFormat
  
  body := json.Marshal(openaiReq)
  httpReq := http.NewRequest("POST", a.baseURL+"/chat/completions", body)
  httpReq.Header.Set("Authorization", "Bearer "+cred.APIKey)
  httpReq.Header.Set("Content-Type", "application/json")
  return httpReq, nil

// OpenAI Adapter - StreamResponse
func (a *OpenAIAdapter) StreamResponse(ctx, resp, req):
  ch := make(chan StreamEvent)
  go func():
    defer close(ch)
    scanner := bufio.NewScanner(resp.Body)
    for scanner.Scan():
      line := scanner.Text()
      if !strings.HasPrefix(line, "data: "): continue
      data := line[6:]
      if data == "[DONE]":
        ch <- StreamEvent{Done: true}
        return
      chunk := parseJSON(data)
      ch <- StreamEvent{
        ID:    chunk["id"],
        Model: chunk["model"],
        Delta: parseDelta(chunk["choices"][0]["delta"]),
        Usage: parseUsageIfPresent(chunk),
      }
  return ch, nil
```
