# Spec 006: Model Catalog & Aliases

## Task/Prompt

Implementasi model catalog:
1. Model metadata (id, display_name, provider, capabilities, context_window, pricing)
2. Model id format: `provider/model` (e.g., `openai/gpt-4o`)
3. Model alias (admin buat alias: `fast-code` → `glm/glm-4.5`)
4. Model permission per user (allow/deny per model/provider)
5. /v1/models endpoint (filtered by user permission)

Referensi 9Router: `/v1/models`, model aliases, permission filtering.

## Tujuan

Sistem model catalog yang:
- Model terdefinisi dengan metadata lengkap
- Alias support untuk simplify usage
- Permission filtering (user hanya lihat model yang diizinkan)
- OpenAI-compatible /v1/models endpoint

## Kenapa Tujuan Ini

Model catalog dipakai di:
- Gateway (spec 010): resolve model string, validate permission
- Combo (spec 011): need model list untuk build combo
- Dashboard: model management UI

## Logic Changes

1. **Model Model**
   ```go
   type Model struct {
       ID               string   // "provider/model" e.g., "openai/gpt-4o"
       DisplayName      string   // "GPT-4o"
       Provider         string   // "openai", "glm", "minimax", etc.
       Model            string   // "gpt-4o", "glm-4.5", etc.
       Capabilities     []string // ["chat", "vision", "tool_call", "embeddings"]
       ContextWindow    int      // 128000
       MaxOutputTokens  int      // 8192
       InputPrice       float64  // per 1M tokens
       OutputPrice      float64  // per 1M tokens
       Enabled          bool     // Global enable/disable
       Tags             []string // ["coding", "cheap", "premium", "long-context"]
       DefaultTimeoutMs int      // 120000
       SupportsStream   bool     // true
       CreatedAt        time.Time
       UpdatedAt        time.Time
   }

   type ModelAlias struct {
       ID        string   // UUID
       Name      string   // "fast-code", "cheap-long-context"
       TargetID  string   // "glm/glm-4.5"
       CreatedBy string   // Admin UUID
       CreatedAt time.Time
   }

   type UserModelPermission struct {
       ID          string   // UUID
       UserID      string   // User UUID
       ModelID     string   // "*" for all, or "provider/model"
       Provider    string   // "*" for all
       AccessType  string   // "allow" | "deny"
       CreatedAt   time.Time
   }
   ```

2. **Model ID Resolution**
   ```
   ResolveModel(modelStr):
     // Check if alias
     alias = repo.FindAlias(modelStr)
     if alias != nil:
       return alias.TargetID
   
     // Already in provider/model format
     if contains("/", modelStr):
       return modelStr
   
     // Infer provider from model name
     switch:
       "claude-*" → "claude/claude-..."
       "gpt-*" or "o1*" → "openai/..."
       "glm-*" → "glm/glm-..."
       "minimax-*" → "minimax/..."
       default → "openai/" + modelStr  // default to openai
   ```

3. **User Permission Filtering**
   ```
   GetVisibleModels(userID):
     user = repo.FindUser(userID)
     
     if user.Role == "admin":
       return repo.ListEnabledModels()
     
     // Get all enabled models
     allModels = repo.ListEnabledModels()
     
     // Filter by user permissions
     perms = repo.GetUserModelPermissions(userID)
     
     return allModels.Filter(m =>
       perms.Allows(m.ID)  // check allow/deny rules
     )
   ```

4. **Permission Check**
   ```
   CanUseModel(userID, modelID):
     perms = repo.GetUserModelPermissions(userID)
     
     // Check exact match
     if perms.HasDeny(modelID): return false
     if perms.HasAllow(modelID): return true
     
     // Check provider wildcard
     provider = extractProvider(modelID)
     if perms.HasDeny(provider + "/*"): return false
     if perms.HasAllow(provider + "/*"): return true
     
     // Check global
     if perms.HasDeny("*"): return false
     if perms.HasAllow("*"): return true
     
     // Default: deny if no rules (whitelist mode)
     return false
   ```

5. **/v1/models Response**
   ```
   GET /v1/models:
     user = GetUserFromApiKey(apiKey)
     models = GetVisibleModels(user.ID)
     
     return {
       object: "list",
       data: models.Map(m => {
         id: m.ID,
         object: "model",
         owned_by: m.Provider
       })
     }
   ```

  perms = modelPerms.GetForUser(userID)

ResolveModel(modelStr):
  // 1. Check alias
  alias = modelAliases.FindByName(modelStr)
  if alias != nil:
    return alias.TargetID
  
  // 2. Already provider/model
  if "/" in modelStr:
    return modelStr
  
  // 3. Infer provider
