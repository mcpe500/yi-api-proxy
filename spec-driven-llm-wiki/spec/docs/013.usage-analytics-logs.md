# Spec 013: Usage Analytics, Request Logs & Audit Logs

## Task/Prompt

Implementasi logging dan analytics:
1. Usage event recording (prompt_tokens, completion_tokens, cost, latency)
2. Request logs (for debugging, dengan redaction)
3. Audit logs (untuk semua admin actions)
4. Analytics endpoints (summary, timeseries, per-user, per-provider)
5. Data retention policy
6. Sensitive data redaction

Referensi 9Router: usage DB, request logs, audit logging, observability.

## Tujuan

Sistem logging yang:
- Track usage untuk billing/analytics
- Debug request dengan request logs
- Security audit trail untuk admin actions
- Redact sensitive data (API keys, passwords, prompts if configured)

## Kenapa Tujuan Ini

Usage logging adalah prerequisite untuk:
- Quota enforcement (spec 012) - perlu tahu usage saat ini
- Analytics dashboard - perlu data
- Audit trail - compliance requirement

## Logic Changes

1. **Usage Event Model**
   ```go
   type UsageEvent struct {
       ID               string   // UUID
       RequestID        string   // ID dari request
       UserID           string   // User UUID
       ApiKeyID         string   // API Key UUID
       RequestedModel   string   // Model yang diminta (alias/combo)
       FinalModel       string   // Model akhir yang dipakai
       Provider         string   // Provider akhir
       StatusCode       int      // HTTP status
       ErrorCode        string   // Jika gagal
       PromptTokens     int      // Input tokens
       CompletionTokens int      // Output tokens
       TotalTokens      int
       EstimatedCost    float64  // Dalam USD
       LatencyMs        int      // Total latency
       FallbackCount    int      // Jumlah fallback
       IsStream         bool
       CreatedAt        time.Time
   }
   ```

2. **Request Log Model** (for debugging)
   ```go
   type RequestLog struct {
       ID          string   // UUID
       RequestID   string   // ID dari request
       UserID      string
       Method      string   // "POST"
       Path        string   // "/v1/chat/completions"
       RequestBody string   // Redacted - API key, password removed
       ResponseStatus int
       ResponseBody string   // Redacted if sensitive
       LatencyMs   int
       CreatedAt   time.Time
   }
   
   // Redaction rules:
   // - Authorization header: "Bearer sk-xxx" → "Bearer ***"
   // - API key in body: "sk-gorouter-xxx" → "sk-gorouter-***"
   // - x-api-key header: removed
   // - Password fields: removed
   // - Provider secrets: removed
   // - Prompt body: optionally redact (configurable)
   ```

3. **Audit Log Model**
   ```go
   type AuditLog struct {
       ID         string   // UUID
       ActorID    string   // User yang melakukan aksi
       ActorEmail string   // Email actor (for display)
       ActorRole  string   // "admin" or "user"
       Action     string   // "user_created", "provider_test", etc.
       TargetType string   // "user", "api_key", "provider", etc.
       TargetID   string   // ID target
       Details    string   // JSON: {old_value, new_value, ...}
       IPAddress  string   // Client IP
       UserAgent  string
       CreatedAt  time.Time
   }
   
   // Audit actions:
   // Auth: login_success, login_failed, logout
   // Users: user_created, user_updated, user_suspended, user_activated, password_reset
   // Keys: api_key_created, api_key_revoked, api_key_rotated
   // Providers: provider_created, provider_updated, provider_test, provider_disabled
   // Models: model_updated, alias_created, combo_created
   // Settings: settings_changed
   ```

4. **Analytics Queries**
   ```
   GetUsageSummary(userID, period):
     SELECT
       COUNT(*) as total_requests,
       SUM(prompt_tokens) as total_prompt_tokens,
       SUM(completion_tokens) as total_completion_tokens,
       SUM(total_tokens) as total_tokens,
       SUM(estimated_cost) as total_cost,
       AVG(latency_ms) as avg_latency,
       COUNT(CASE WHEN status_code >= 400 THEN 1 END) as error_count
     FROM usage_events
     WHERE user_id = ? AND created_at >= ?
   
   GetUsageTimeseries(userID, period, granularity):
     // Group by hour/day/month
     SELECT
       DATE_TRUNC(granularity, created_at) as time,
       COUNT(*) as requests,
       SUM(total_tokens) as tokens
     FROM usage_events
     WHERE user_id = ? AND created_at >= ?
     GROUP BY 1
   
   GetUsageByProvider(userID, period):
     SELECT
       provider,
       COUNT(*) as requests,
       SUM(total_tokens) as tokens,
       SUM(estimated_cost) as cost
     FROM usage_events
     WHERE user_id = ? AND created_at >= ?
     GROUP BY provider
   
   GetUsageByModel(userID, period):
     SELECT
       final_model,
       COUNT(*) as requests,
       SUM(total_tokens) as tokens
     FROM usage_events
     WHERE user_id = ? AND created_at >= ?
     GROUP BY final_model
   ```

5. **Retention Policy**
   ```
   Data Retention (configurable):
   - Usage events: 180 days default
   - Request logs: 30 days default
   - Audit logs: 365 days default (or forever)
   
   Cleanup job (run daily):
     DELETE FROM usage_events WHERE created_at < now() - retention_days
     DELETE FROM request_logs WHERE created_at < now() - retention_days
     DELETE FROM audit_logs WHERE created_at < now() - retention_days  // if not forever
   ```

```
RecordUsageEvent(req *NormalizedChatRequest, result *ExecutionResult):
  event := UsageEvent{
    ID:               uuid.New(),
    RequestID:        req.RequestID,
    UserID:           req.UserID,
    ApiKeyID:         req.ApiKeyID,
    RequestedModel:   req.Model,
    FinalModel:       result.Model,
    Provider:         result.Provider,
    StatusCode:       result.StatusCode,
    ErrorCode:        result.ErrorCode,
    PromptTokens:     result.Usage.PromptTokens,
    CompletionTokens: result.Usage.CompletionTokens,
    TotalTokens:      result.Usage.TotalTokens,
    EstimatedCost:    calculateCost(result.Usage, result.Provider),
    LatencyMs:        result.LatencyMs,
    FallbackCount:    result.FallbackCount,
    IsStream:         req.Stream,
    CreatedAt:        time.Now(),
  }
  usageRepo.Create(event)

RedactRequestBody(body []byte) string:
  // Replace API keys
  body = regexReplace(`sk-gorouter-[a-z]+_[a-zA-Z0-9]+`, "sk-gorouter-***", body)
  // Replace Authorization headers
  body = regexReplace(`Authorization:\s*Bearer\s+[^\s]+`, "Authorization: Bearer ***", body)
  // Remove password fields
  body = regexReplace(`"password"\s*:\s*"[^"]+"`, `"password":"***"`, body)
  // Remove x-api-key
  body = regexReplace(`"x-api-key"\s*:\s*"[^"]+"`, "", body)
  return body
```
