# Spec 014: Dashboard API Endpoints (All /api/* Routes)

## Task/Prompt

Implementasi semua management API endpoints:
1. Auth endpoints (login, logout, me, change-password)
2. Admin user management endpoints
3. API key management endpoints (admin + user)
4. Provider management endpoints
5. Model, alias, combo management endpoints
6. Usage/analytics endpoints (admin + user)
7. Settings endpoints
8. All endpoints protected by JWT auth + RBAC middleware

## Tujuan

Dashboard API yang lengkap untuk:
- Admin mengelola semua resource
- User mengelola key dan lihat usage sendiri
- Semua aksi ter-audit

## Kenapa Tujuan Ini

Dashboard API adalah interface antara frontend dashboard dan backend. Semua CRUD operations melalui sini. Ini menyatukan semua service dari spec 002-013.

   func RegisterAPIRoutes(r chi.Router, svc *Services) {
       // Public
       r.Post("/api/auth/login", svc.AuthHandler.Login)
       
       // Protected (JWT required)
       r.Group(func(r chi.Router) {
           r.Use(middleware.RequireAuth(svc.JWTSecret))
           
           // Auth
           r.Post("/api/auth/logout", svc.AuthHandler.Logout)
           r.Get("/api/auth/me", svc.AuthHandler.GetMe)
           r.Post("/api/auth/change-password", svc.AuthHandler.ChangePassword)
           
           // User self-service
           r.Route("/api/me", func(r chi.Router) {
               r.Get("/api-keys", svc.KeyHandler.ListMyKeys)

           // Admin only
           r.Route("/api/admin", func(r chi.Router) {

4. **Request Validation**
   ```go
   // Each handler validates input before calling service
   func (h *UserHandler) CreateUser(w, r) {
       var input CreateUserInput
       if err := json.NewDecoder(r.Body).Decode(&input); err != nil {
           errorResponse(w, 400, "Invalid JSON")
           return
       }
       if input.Email == "" { errorResponse(w, 400, "Email required"); return }
       if input.Password == "" { errorResponse(w, 400, "Password required"); return }
       if len(input.Password) < 8 { errorResponse(w, 400, "Password min 8 chars"); return }
       if input.Role != "admin" && input.Role != "user" {
           errorResponse(w, 400, "Role must be admin or user")
           return
       }
       // ...
   }
   ```

## Pseudocode

```
// Example: Create User handler
func (h *UserHandler) CreateUser(w http.ResponseWriter, r *http.Request):
  actor := middleware.GetUserFromContext(r.Context())
  
  var input CreateUserInput
  json.Decode(r.Body, &input)
  
  // Validate
  validate(input)  // email, password, role
  
  // Call service
  user, err := h.UserService.CreateUser(r.Context(), actor.ID, input)
  if err == ErrEmailExists:
    errorResponse(w, 409, "Email already exists")
    return
  if err != nil:
    errorResponse(w, 500, "Internal error")
    return
  
  // Audit
  h.AuditService.Log(r.Context(), actor, "user_created", "user", user.ID, map[string]any{
    "email": user.Email, "role": user.Role,
  })
  
  createdResponse(w, user)

// Example: List Audit Logs (admin only)
func (h *AuditHandler) ListAuditLogs(w http.ResponseWriter, r *http.Request):
  filter := AuditFilter{
    Page:     r.URL.Query().Get("page"),
    PageSize: r.URL.Query().Get("page_size"),
    Action:   r.URL.Query().Get("action"),
    ActorID:  r.URL.Query().Get("actor_id"),
    From:     r.URL.Query().Get("from"),
    To:       r.URL.Query().Get("to"),
  }
  
  logs, total, err := h.AuditService.GetLogs(r.Context(), filter)
  listResponse(w, logs, total, filter.Page)
```
