# Spec 015: Adapters: CommandCode, OpenCode Go & Compat Endpoints

## Task/Prompt

Implementasi adapter dan endpoint tambahan:
1. **CommandCode adapter** - Custom request/response mapping
2. **OpenCode Go adapter** - Local/remote, no-auth/API key
3. **POST /v1/responses** - OpenAI Responses API compatibility
4. **POST /v1/messages** - Claude/Anthropic Messages API compatibility
5. **POST /v1/messages/count_tokens** - Mock token counting
6. **POST /v1/embeddings** - Embeddings endpoint

Referensi 9Router: CommandCode executor, OpenCode executor, /v1/responses, /v1/messages, embeddings handler.

## Tujuan

Compatibility endpoints yang:
- CommandCode: map OpenAI request → CC format, CC response → OpenAI format
- OpenCode Go: support local (no-auth) dan remote mode
- /v1/responses: OpenAI Responses API format
- /v1/messages: Claude Messages API format
- Embeddings: multi-provider support

## Kenapa Tujuan Ini

MVP v0.3 menambahkan compatibility endpoints untuk:
- CommandCode dan OpenCode Go support
- /v1/responses untuk Codex/tools yang pakai format ini
- /v1/messages untuk Claude desktop/tools
- Embeddings untuk RAG/semantic search

## Logic Changes

1. **CommandCode Adapter**
   ```go
   type CommandCodeAdapter struct {
       BaseURL string
   }
   ```
   
   CommandCode membutuhkan:
   - Request mapping: OpenAI format → CC format
   - Response mapping: CC format → OpenAI format
   - Streaming support (jika CC mendukung)
   - Error mapping ke OpenAI-compatible errors
   - Auth: cookie/header based
   
   Key differences:
   - Different endpoint paths
   - Different request body structure
   - Different response structure
   - Custom authentication

2. **OpenCode Go Adapter**
   ```go
   type OpenCodeGoAdapter struct {
       BaseURL string
       AuthType string  // "no_auth" for local, "api_key" for remote
   }
   ```
   
   OpenCode Go:
   - Local mode: no auth, localhost endpoint
   - Remote mode: API key auth
   - Model naming: `opencode-go/default`, `opencode-go/<model>`
   - Simple adapter: mostly passthrough

3. **POST /v1/responses** (OpenAI Responses API)
   ```
   Input format (OpenAI Responses):
   {
     "model": "...",
     "input": [
       { "role": "user", "content": "..." }
     ],
     "stream": true
   }
   
   Output: OpenAI Responses SSE format (different from chat completions)
   
   Implementation:
   1. Parse Responses API request
   2. Convert to NormalizedChatRequest (map input[] → messages[])
   3. Execute via routing service
   4. Convert response back to Responses API format
   ```

4. **POST /v1/messages** (Claude Messages API)
   ```
   Input format (Claude Messages):
   {
     "model": "...",
     "messages": [...],
     "max_tokens": 1024,
     "stream": true
   }
   
   Output: Claude Messages SSE format
   
   Implementation:
   1. Parse Claude Messages request
   2. Convert to NormalizedChatRequest
   3. Execute via routing service
   4. Convert response to Claude Messages format
   ```

5. **POST /v1/messages/count_tokens**
   ```
   Input: { "model": "...", "messages": [...] }
   Output: { "input_tokens": 1234 }
   
   Implementation: Simple estimation
   - Sum char count of all messages
   - Estimate: total_chars / 4
   - Return { input_tokens: estimated_count }
   ```

6. **POST /v1/embeddings**
   ```
   Input (OpenAI format):
   {
     "model": "openai/text-embedding-3-small",
     "input": "text or array",
     "encoding_format": "float",
     "dimensions": 1536
   }
   
   Output:
   {
     "object": "list",
     "data": [{ "object": "embedding", "index": 0, "embedding": [...] }],
     "model": "...",
     "usage": { "prompt_tokens": 0, "total_tokens": 0 }
   }
   
   Provider adapters:
   - OpenAI: native embeddings API
   - GLM: if supports embeddings
   - OpenAI-compatible: pass through
   ```

## Code Changes

1. **internal/adapters/commandcode/adapter.go**
   - CommandCodeAdapter implementing ProviderAdapter
   - Custom request/response mapping
   - Streaming support

2. **internal/adapters/opencodego/adapter.go**
   - OpenCodeGoAdapter implementing ProviderAdapter

   - Mostly passthrough

3. **internal/gateway/responses/handler.go**

## Pseudocode

```
// /v1/responses handler
POST /v1/responses:
  body = parseJSON(request)
  
  // Convert Responses API → Normalized
  req = NormalizedChatRequest{
    Model:    resolveModel(body.model),
    Messages: mapResponsesInputToMessages(body.input),
    Stream:   body.stream,
  }
  
  // Execute
  result = routingService.Execute(ctx, req)
  
  // Convert back to Responses API format
  if body.stream:
    SSE headers
    for event in result.StreamEvents:
      responsesEvent = mapToResponsesFormat(event)
      write "data: " + json(responsesEvent) + "\n\n"
  else:
    responsesResp = mapToResponsesResponse(result.Response)
    json(responsesResp)

// /v1/messages handler (Claude format)
POST /v1/messages:
  body = parseJSON(request)
  
  // Convert Claude → Normalized
  req = NormalizedChatRequest{
    Model:    resolveModel(body.model),
    Messages: mapClaudeMessagesToOpenAI(body.messages),
    MaxTokens: body.max_tokens,
    Stream:   body.stream,
  }
  
  // Execute
  result = routingService.Execute(ctx, req)
  
  // Convert to Claude format
  if body.stream:
    SSE headers
    for event in result.StreamEvents:
      claudeEvent = mapToClaudeFormat(event)
      write "event: content_block_delta\ndata: " + json(claudeEvent) + "\n\n"
  else:
    claudeResp = mapToClaudeResponse(result.Response)
    json(claudeResp)

// /v1/embeddings handler
POST /v1/embeddings:
  body = parseJSON(request)
  
  // Get adapter for model's provider
  modelID = resolveModel(body.model)
  adapter = registry.Get(extractProvider(modelID))
  cred = getProviderCredential(modelID)
  
  // Call adapter's embedding method
  result = adapter.Embeddings(ctx, body, cred)
  
  json(result)
```
