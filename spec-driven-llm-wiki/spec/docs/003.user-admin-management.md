# Spec 003: User & Admin Management (CRUD, RBAC)

## Task/Prompt

Implementasi user & admin management:
1. User model dengan field lengkap (id, email, name, role, status, password_hash, timestamps)
2. CRUD user oleh admin (create, read, update, suspend, activate, delete)
3. RBAC: role `admin` dan `user` dengan permission matrix
4. Safety rule: minimal 1 admin aktif selalu ada
5. Admin bisa buat admin lain
6. Semua aksi tercatat di audit log
7. Password reset oleh admin

Referensi PRD: Section 5 (Role dan Permission), Section 6.2 (User & Admin Management).

## Tujuan

Sistem user management yang:
- Admin bisa CRUD user dan admin lain
- RBAC sederhana (admin vs user) tapi effective
- Safety: tidak bisa hapus admin terakhir
- Semua aksi ter-audit

## Kenapa Tujuan Ini

User management adalah prerequisite:
- API Key (spec 004) terikat ke user
- Provider (spec 005) dibuat oleh admin
- Quota (spec 012) per user
- Usage (spec 013) per user

## Logic Changes

1. **User Model**
   ```go
   type User struct {
       ID           string    // UUID
       Email        string    // Unique
       Name         string
       Role         string    // "admin" | "user"
       Status       string    // "active" | "suspended" | "deleted"
       PasswordHash string
       CreatedBy    *string   // UUID admin pembuat, nil untuk bootstrap
       CreatedAt    time.Time
       UpdatedAt    time.Time
       LastLoginAt  *time.Time
   }
   ```

2. **Repository Interface**
   ```go
   type UserRepository interface {
       Create(ctx context.Context, user *User) error
       FindByID(ctx context.Context, id string) (*User, error)
       FindByEmail(ctx context.Context, email string) (*User, error)
       List(ctx context.Context, filter UserFilter) ([]*User, error)
       Update(ctx context.Context, user *User) error
       UpdateStatus(ctx context.Context, id, status string) error
       UpdatePassword(ctx context.Context, id, hash string) error
       UpdateLastLogin(ctx context.Context, id string) error
       Delete(ctx context.Context, id string) error
       CountActiveAdmins(ctx context.Context) (int, error)
   }
   ```

3. **RBAC Permission Matrix**

   | Action | Admin | User |
   |--------|-------|------|
   | Create user | Yes | No |
   | Create admin | Yes | No |
   | Edit user | Yes | No |
   | Suspend user | Yes | No |
   | Reset password | Yes | No |
   | View all users | Yes | No |
   | View own profile | Yes | Yes |
   | Use /v1/* API | If has key | If has key |

4. **Safety Rules**
   - Tidak bisa suspend/hapus admin terakhir
   - Tidak bisa suspend user yang sudah suspended
   - Email harus unik
   - Password min 8 karakter

5. **Audit Events**
   - `user_created`: { actor_id, target_id, role }
   - `user_updated`: { actor_id, target_id, changes }
   - `user_suspended`: { actor_id, target_id, reason }
   - `user_activated`: { actor_id, target_id }
   - `password_reset`: { actor_id, target_id }
   - `user_deleted`: { actor_id, target_id }

## Pseudocode

```
CreateUser(actorID, email, name, role, password):
  // Validate
  if role not in ["admin", "user"] → error
  if len(password) < 8 → error
  existing = repo.FindByEmail(email)
  if existing != nil → error "email already exists"
  
  // Create
  hash = bcrypt.HashPassword(password)
  user = User{
    ID: uuid.New(), Email: email, Name: name,
    Role: role, Status: "active", PasswordHash: hash,
    CreatedBy: actorID, CreatedAt: now, UpdatedAt: now,
  }
  repo.Create(user)
  audit.Log("user_created", actorID, { target_id: user.ID, role })
  return user

SuspendUser(actorID, userID):
  user = repo.FindByID(userID)
  if user == nil → error "not found"
  if user.Status == "suspended" → error "already suspended"
  if user.Role == "admin":
    activeAdmins = repo.CountActiveAdmins()
    if activeAdmins <= 1 → error "cannot suspend last admin"
  
  repo.UpdateStatus(userID, "suspended")
  // Also invalidate all API keys for this user
  apiKeys.RevokeAllForUser(userID)
  audit.Log("user_suspended", actorID, { target_id: userID })
```

### Edge Cases
- Suspend last admin → 403
- Delete self → 403
- Create admin with existing email → 409
- Non-admin tries to create user → 403
