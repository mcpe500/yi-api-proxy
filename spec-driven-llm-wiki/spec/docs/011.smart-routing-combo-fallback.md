# Spec 011: Smart Routing & Combo Fallback

## Task/Prompt

Implementasi smart routing dan combo fallback engine:
1. Combo model (chain beberapa model/provider)
2. Routing strategies: priority_fallback, weighted_round_robin, least_cost, quota_aware
3. Account selection per provider (multi-account)
4. Fallback eligible errors (429, 5xx, timeout, quota)
5. Fallback non-eligible errors (400, 401, 403 untuk alasan tertentu)
6. Cooldown mechanism per account
7. Combo testing endpoint

Referensi 9Router: combo fallback, combo strategy, account fallback, provider cooldown.

## Tujuan

Sistem routing yang:
- Otomatis fallback saat provider gagal
- Combo support untuk chain model
- Multi-account load balancing
- Configurable strategy per combo

## Kenapa Tujuan Ini

Routing adalah core feature yang membuat gorouter berbeda dari proxy biasa:
- Fallback otomatis → 99% uptime
- Combo → maximize subscription, minimize cost
- Multi-account → spread load, avoid rate limit

## Logic Changes

1. **Combo Model**
   ```go
   type Combo struct {
       ID          string       // UUID
       Name        string       // "coding-default", "cheap-combo"
       Description string
       Strategy    string       // "priority_fallback" | "weighted_round_robin"
       Enabled     bool
       Items       []ComboItem  // Ordered list
       CreatedBy   string
       CreatedAt   time.Time
       UpdatedAt   time.Time
   }

   type ComboItem struct {
       ID         string
       ComboID    string
       ModelID    string       // "glm/glm-4.5"
       Priority   int          // Lower = higher priority
       Weight     int          // For weighted round-robin
       Conditions string       // JSON: {"max_cost_per_request": 0.5}
   }
   ```

2. **Routing Strategy Interface**
   ```go
   type RoutingStrategy interface {
       SelectNext(ctx context.Context, items []ComboItem, used []string) (*ComboItem, error)
       RecordResult(item *ComboItem, success bool, latencyMs int)
       Reset()
   }

   // Implementations:
   - PriorityFallbackStrategy: Try in order, skip used
   - WeightedRoundRobinStrategy: Weight-based, sticky sessions
   - LeastCostStrategy: Sort by input_price + output_price
   - QuotaAwareStrategy: Avoid models with low remaining quota
   - LatencyAwareStrategy: Sort by p95 latency
   ```

3. **Fallback Decision Logic**
   ```
   IsFallbackEligible(error):
     // 429 Rate Limit → YES
     // 502/503/504 Server Error → YES
     // Timeout → YES
     // Quota exceeded → YES (different quota, try another account)
     
     // 401/403 Auth Error → MAYBE
     //   If can refresh token → retry once
     //   If different account available → try that account
     
     // 400 Bad Request → NO
     //   Invalid JSON → NO
     //   Missing required field → NO
     //   Model not found → NO
     
     // Content policy error → NO
     //   Unless it's provider-specific failure
   ```

4. **Account Selection per Provider**
   ```
   GetActiveAccount(provider, excludeIDs []string):
     accounts = providers.GetByProvider(provider)
     active = accounts.Filter(a =>
       a.Status == "active" AND
       (a.CooldownUntil == nil OR a.CooldownUntil < now) AND
       a.ID NOT IN excludeIDs
     )
     SortByPriority(active)
     return first(active)
   ```

5. **Execute with Fallback**
   ```
   ExecuteWithFallback(ctx, req):
     modelID = req.Model
     
     // Check if combo
     combo = combos.FindByName(modelID)
     if combo != nil:
       return ExecuteCombo(ctx, req, combo)
     
     // Single model
     return ExecuteSingleModel(ctx, req, modelID)

   ExecuteCombo(ctx, req, combo):
     strategy = NewStrategy(combo.Strategy)
     usedAccounts := []
     fallbackCount := 0
     
     for attempt in range(maxAttempts):
       item := strategy.SelectNext(combo.Items, usedItems)
       if item == nil: break
       
       result := ExecuteSingleModel(ctx, req, item.ModelID, usedAccounts)
       
       if result.Success:
         strategy.RecordResult(item, true, result.LatencyMs)
         return result
       
       if !IsFallbackEligible(result.Error):
         return result  // Non-retryable error
       
       // Mark account unavailable
       providers.MarkCooldown(result.AccountID, result.CooldownMs, result.Error)
       usedAccounts = append(usedAccounts, result.AccountID)
       fallbackCount++
       
       strategy.RecordResult(item, false, result.LatencyMs)
     
     return Error("all_providers_failed", fallbackCount)
   ```

6. **Cooldown Duration Calculation**
   ```
   CalculateCooldown(statusCode, errorText, backoffLevel, resetsAtMs):
     // Provider reports reset time
     if resetsAtMs != nil and resetsAtMs > now:
       return resetsAtMs - now  // Use provider's time
     
     // Text-based detection
     if contains(errorText, "rate limit"): baseCooldown = 60s
     if contains(errorText, "quota exceeded"): baseCooldown = 3600s
     
     // Status-based
     if statusCode == 429: baseCooldown = 60s
     if statusCode >= 500: baseCooldown = 30s
     
     // Exponential backoff
     cooldown = min(baseCooldown * (2 ^ backoffLevel), 300000)  // max 5min
     return cooldown
   ```

## Pseudocode

```
ExecuteWithFallback(ctx, req, modelID):
  // 1. Check if combo
  combo = combos.FindByName(modelID)
  
  if combo != nil:
    strategy = NewStrategy(combo.Strategy)
    return ExecuteCombo(ctx, req, combo, strategy)
  
  // 2. Single model path
  return ExecuteSingleModel(ctx, req, modelID, nil)

ExecuteCombo(ctx, req, combo, strategy):
  usedAccounts := []
  usedItems := []
  
  for {
    // Select next item
    item := strategy.SelectNext(combo.Items, usedItems)
    if item == nil:
      return allProvidersFailed()
    
    // Get account for this model
    provider := extractProvider(item.ModelID)
    account := providers.GetActiveAccount(provider, usedAccounts)
    if account == nil:
      usedItems = append(usedItems, item.ID)
      continue
    
    // Execute request
    result := executeRequest(ctx, req, item.ModelID, account)
    
    if result.Success:
      return result
    
    // Handle failure
    if !IsFallbackEligible(result.Error):
      return result
    
    // Mark account as unavailable
    providers.MarkCooldown(account.ID, result.CooldownMs, result.ErrorText)
    usedAccounts = append(usedAccounts, account.ID)
    usedItems = append(usedItems, item.ID)
    
    // Record for strategy
    strategy.RecordResult(item, false, result.LatencyMs)
  }
```
